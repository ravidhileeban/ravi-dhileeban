# Resume

Place your resume PDF in this folder using this exact file name:

    Ravi-Dhileeban-Resume.pdf

The site links to `assets/resume/Ravi-Dhileeban-Resume.pdf`. Replacing the file
updates every download link on the site — no code change required. If you prefer a
different file name, update `resumePath` in `src/app/data/profile.data.ts`.
